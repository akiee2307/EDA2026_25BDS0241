# 25BDS0241 - Exploratory Data Analysis

Exploratory Data Analysis (EDA) performed on `eda1.csv` using Python and pandas.

## Contents
- `EDA1.ipynb` / `eda1.py` — analysis script
- `eda1.csv` — dataset used

## What it does
- Loads the dataset with pandas
- Displays first and last 5 records (`head()`, `tail()`)
- Shows dataset shape (rows, columns)
- Lists column names and data types
- Displays metadata using `info()`

## How to run
```bash
pip install pandas
python3 eda1.py
```
or open `EDA1.ipynb` in Jupyter/VS Code and run all cells.
